# KOTLIN PRACTICE PROJECTS
Welcome to my Kotlin Practice Projects repository.

This repository contains a collection of console-based Kotlin applications built throughout my Kotlin learning journey. Each project explores different programming concepts, from language fundamentals to intermediate and advanced topics such as generics, JSON serialization, regular expressions, coroutines, and file handling.

The goal of this repository is to practice writing clean, reusable Kotlin code while solving real-world programming problems.

> Click into any project folder for a detailed README specific to that project.
